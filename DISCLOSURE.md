# Disclosure: use of software tools

Portions of the code, tests and documentation in this repository, in particular much of the `cng_datasets` package (the vector, raster and multidimensional pipelines, the Kubernetes job generators and the Docker image), were drafted with the aid of large language model coding tools: Anthropic Claude models, most recently Claude Opus 5.5 (model ID `claude-opus-5-5`), accessed through the Claude Code command-line tool, beginning February 2026.

The authors directed this work and reviewed, tested, and validated the results, including the test suite run in the project's Docker image on every pull request and verification runs on the NRP Nautilus cluster. The authors take full responsibility for the code and documentation, and any errors they contain.
