# API Reference

Every module below works on its own from Python, on a laptop or a single large machine. The Kubernetes workflows generated by the CLI run the same code inside each job.

- [Vector processing](api/vector.md): H3 tiling and repartitioning of vector data
- [Raster processing](api/raster.md): COG creation and raster to H3 conversion
- [Multidimensional processing](api/mdim.md): NetCDF and Zarr cubes to H3
- [Kubernetes](api/k8s.md): job and workflow generation for Kubernetes and Armada
- [Storage](api/storage.md): S3 bucket management and rclone syncing
